\footnotesize
The table reports hypergeometric \(P\) values for each combination
of cell type, method, and regulatory reference dataset. For a given gene,
\(N\) is the number of candidate peaks in the background set, and \(K\)
is the number of those peaks that overlap regions annotated for that gene
in the reference dataset. Similarly, \(n\) is the number of peaks linked
to the gene by a significant association for the given method, and \(k\)
is the number of those peaks that overlap the same annotated regions.
For each test, the four counts are summed across genes to obtain
\(\sum N\), \(\sum K\), \(\sum n\), and \(\sum k\).
